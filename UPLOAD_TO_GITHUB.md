## Browser upload steps

1. Sign in to GitHub.
2. Open the existing repository you want to update, or create a new repository named `sales-insights-dashboard-abc-france`.
3. Select **Add file → Upload files**.
4. Upload the contents inside this project folder.
5. Enter the commit message:

```text
Add completed Power BI sales insights dashboard
```

6. Select **Commit changes**.
7. Add a dashboard screenshot to the `screenshots` folder.
8. Pin the repository to your GitHub profile.
9. Add the repository link to the Featured section of LinkedIn.

## Important

Upload the files and folders inside this package—not the ZIP file itself—so the README displays correctly on the repository homepage.
