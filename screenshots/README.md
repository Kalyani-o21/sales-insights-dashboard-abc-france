# Dashboard Screenshots

Add a clear screenshot of the complete Power BI report page to this folder.

Recommended filename:

```text
dashboard-overview.png
```

Then add the following line to the main `README.md`:

```markdown
![Sales Insights Dashboard](screenshots/dashboard-overview.png)
```

For the best result, hide the Power BI Filters, Visualisations, and Data panes before taking the screenshot.
